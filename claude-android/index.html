Frequently asked questions

Does Claude Code for Android require Root, Termux, or PRoot?

No. It runs 100% natively in Android userspace inside its own standalone sandbox (com.cc.ide) with zero Termux dependency and zero PRoot syscall translation overhead.

How are my credentials protected?

Claude.ai OAuth tokens stay strictly inside the app's private 0600 sandbox, and custom API keys entered in Settings → API & Model are encrypted with hardware-backed AndroidKeyStore AES-256-GCM (SecretStore) and injected only into memory.

How do elevated uid=2000(shell) ADB commands work?

Nothing elevated is active by default. Whenever you need ADB-level shell access, open Settings → Plugins, install AGY ADB Bridge, and pair once using Android's 6-digit Wireless Debugging code (or authorize via Shizuku).

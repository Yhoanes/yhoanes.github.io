Frequently asked questions

Does Codex for Android require Root, Termux, or PRoot?

No. Codex for Android runs directly on Android ARM64 inside its own standalone sandbox (com.ce.ide) using static ARM64 binaries and a 10-byte prefix-aligned Bionic userspace with zero PRoot overhead.

Why does Codex launch instantaneously despite having 15,350 webview files?

All 15,350 webview modules are packed into a single byte-indexed archive (webview-bundle.pak), avoiding tens of thousands of filesystem metadata syscalls on mobile UFS flash and serving assets in under 2 ms.

Can I install side-by-side Release and Dev builds?

Yes. ./build.sh produces com.ce.ide (port 45197), while ./build.sh --dev produces an isolated side-by-side com.ce.dev APK (port 45198).
